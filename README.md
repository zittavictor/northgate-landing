# NorthGate Landing Page

NorthGate is an e-invoicing and tax compliance platform for Nigerian businesses. It helps companies manage invoices while staying compliant with FIRS standards.

## Project Structure

- **frontend**: React application for the landing page.
- **backend**: FastAPI server for processing and validation.

## Features

- Smart e-invoicing.
- Real-time tax validation.
- FIRS compliance.
- Audit-ready reporting.

## Setup

To run the project locally, you will need to set up both the frontend and backend. Follow the standard installation steps for React and Python.
